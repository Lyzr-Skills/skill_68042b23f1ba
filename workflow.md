# Workflow Specification

Step-by-step pipeline execution sequence.

## Pipeline Iteration Loop
1. Parse goals and validate timeframe (Gate 1, 2).
2. Gather metrics, tag actuals/benchmarks/assumptions (Gate 3, 4, 5).
3. Compute deterministic growth math targets.
4. Execute bottleneck analysis.
5. Score and filter channels.
6. Design and order experiments by priority.
7. Perform resource constraints viability check (Gate 6).
8. Assert numeric success thresholds exist on all experiments (Gate 7).
9. Output executive strategy report.
