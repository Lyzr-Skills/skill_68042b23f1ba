# Go-To-Market (GTM) Strategy Skill

This skill converts a business goal (e.g. "I need 20 customers") into a deterministic, measurable, and adaptive execution system.

## Entry Points
- Goal validation
- Deterministic growth calculations
- Priority-ranked experimental backlog
- Weekly sequenced execution lists

## System Requirements
- Strict compliance with JSON schemas in `schemas/`.
- No LLM-driven arithmetic.
