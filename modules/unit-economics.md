# Unit Economics Module

Calculate and enforce viability thresholds.

## Calculations
- **LTV:CAC Ratio**: Check if ratio is healthy (e.g. $\ge 3$).
- **Payback Period**: Time required to recover acquisition costs.
- **Channel Economics**: Isolate unit economics per channel to select higher-margin options over low-margin high-volume.
- Validate metrics and output via `schemas/unit-economics.json`.
